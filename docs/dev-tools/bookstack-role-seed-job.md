# bookstack-role-seed (Job)

Post-install hook that seeds BookStack roles (e.g. mapping an OIDC/LDAP group to a
BookStack role so SSO users land with the right permissions).

- **Template:** `src/dev-tools/templates/bookstack/bookstack--role-seed-job.yaml`
- Idempotent.

See [bookstack](bookstack.md).
